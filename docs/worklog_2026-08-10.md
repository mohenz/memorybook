# MEMOry 작업 기록 — 2026-08-10

## 작업 범위

### 메모 화면

- PC 메모 상세 화면의 모바일형 빠른 작업 패널을 제거했습니다.
- 메모 제목, 본문, 메타 정보와 TO-DO 표시 글꼴을 각각 2px 축소했습니다.
- 메모 작성일과 TO-DO 등록일 또는 목표일이 같은 경우 해당 TO-DO를 메모 화면에 표시하도록 연결했습니다.
- PC와 모바일 메모 화면에서 연결된 TO-DO의 내용, 목표일, 상태를 수정하거나 삭제할 수 있도록 했습니다.

### 독립 TO-DO 관리

- 메모 내부 체크리스트에 종속되던 할 일을 독립 `TodoItem` 데이터로 분리했습니다.
- 기존 메모 체크리스트는 최초 로딩 시 독립 TO-DO로 자동 이전하고 메모 소유 관계를 제거합니다.
- 독립 TO-DO를 Supabase `memo_states.state`에 함께 저장하도록 클라우드 동기화 구조를 확장했습니다.
- TO-DO 등록 시 목표일을 입력하도록 했습니다.
- 예정 및 진행 항목에 `D-Day`, `D-n`, `n일 지남` 형식으로 목표일까지 남은 날짜를 표시합니다.
- TO-DO LIST와 연결된 메모 화면에서 내용·목표일 수정, 상태 변경, 삭제 기능을 제공합니다.
- 예정·진행·완료 각 열은 목표일이 오늘과 가까운 순서로 정렬하고 목표일이 없는 항목은 마지막에 표시합니다.

### 캘린더 및 일정

- 선택 날짜 상세 패널에 `일정 추가`, `메모 추가` 버튼을 배치하고 선택 날짜를 작성 화면에 전달합니다.
- 캘린더 보기 방식에 `일정` 보기를 추가했습니다.
- 일정 보기에서 선택 월의 일정과 TO-DO를 날짜별로 묶어 표시합니다.
- 일정 행에는 날짜, 종일 여부 표시, 일정 내용과 시간을 표시합니다.
- TO-DO 행에는 등록일/목표일 관계, 예정·진행·완료 상태와 내용을 표시합니다.
- 반복 일정은 원본 날짜가 아닌 해당 월의 실제 발생 날짜에 게시합니다.
- 종일 표시는 실제 종일 일정이면 파란색, 시간 일정이면 회색으로 표시합니다.
- TO-DO 예정·진행 상태 텍스트는 파란색, 완료 상태는 회색으로 표시합니다.
- 주요 일정 리마인드의 표 보기와 카드 보기에 실제 일정 발생 날짜를 추가했습니다.

## 데이터 호환성

- 기존 체크리스트 항목의 ID, 내용과 상태를 유지하여 독립 TO-DO로 이전합니다.
- 기존 항목에 목표일이 없으면 등록일을 기준으로 표시하며 수정 화면에서 목표일을 추가할 수 있습니다.
- 별도 테이블 마이그레이션 없이 기존 JSON 상태 필드에 `todos` 배열을 추가하여 이전 저장 데이터와 호환됩니다.

## 추가 작업 — 캘린더 상세 TO-DO

- 선택 날짜 상세 패널의 표시 순서를 `일정 → TO-DO → 메모`로 확장했습니다.
- TO-DO에는 상태, 내용, 등록일과 목표일을 표시합니다.
- 목표일이 있는 미완료 항목을 패널에 표시하고 완료 항목과 목표일 없는 항목은 제외합니다.
- 목표일이 오늘보다 이전인 미완료 항목은 기존 예정·진행 상태 대신 `지연`으로 표시하고 오류 색상으로 강조합니다.
- 빈 목록 안내 문구는 `오늘 예정 및 진행인 할일이 없습니다`로 적용했습니다.
- 로컬 브라우저에서 8월 10일 기준 미래 목표일 TO-DO 7개 표시를 확인했습니다.
