## 진단 과정에서 확인/배제한 것
- **캐싱 문제 배제**: 시크릿 모드(로컬 캐시·서비스워커 이력이 전혀 없는 상태)에서도 #3~#5이 동일하게 재현됨 → 서비스워커/브라우저 캐시/Firebase Hosting 캐시 헤더는 원인에서 제외.
- **원격(내 쪽) 검증과의 불일치**: 완전히 새 브라우저 컨텍스트로 운영 URL(`https://archive-store-fae71.web.app`)을 직접 접속해 확인했을 때는 스플래시 정상 동작(1회 표시 후 재로드 시 스킵), 콘솔 에러 없음 — 즉 원격 환경(Desktop Chrome, 375×812 에뮬레이션)에서는 재현되지 않음. 실제 재현 환경(Android Chrome 실기)과의 차이가 원인일 가능성.
- **스크롤 테스트는 무의미했음**: 앱 전체가 `overflow-hidden`으로 페이지 레벨 스크롤을 막아놓은 구조라, "스크롤해도 안 나타난다"는 결과로는 "화면 밖으로 밀林" vs "아예 렌더링 안 됨"을 구분할 수 없었음.
