## 초기 클라우드 동기화 오류 수정

- 앱 초기 실행 시 `notes` 조회 단계에서 `PGRST303`이 발생하며 화면이 비어 보이던 문제를 수정했습니다.
- 원인은 만료되었거나 갱신 적용 전인 Supabase 인증 토큰으로 초기 데이터 조회가 시작되는 경합으로 판단했습니다.
- Supabase 인증 이벤트 콜백에서는 사용자 알림만 다음 이벤트 루프로 지연하여, 클라이언트가 갱신 토큰을 먼저 적용하도록 변경했습니다.
- 초기 조회 결과에 `PGRST303`이 있으면 `refreshSession()`을 실행한 뒤 전체 클라우드 데이터를 한 번 자동 재조회하도록 보강했습니다.
- 재시도 실패 시 기존처럼 오류 화면을 유지하며, 로컬 상태를 빈 데이터로 덮어쓰지 않습니다.
